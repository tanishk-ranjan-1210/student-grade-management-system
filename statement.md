# Student Grade Management System

## Problem Statement

Managing student marks and calculating results manually can take time and may lead to calculation or data-entry errors. It can also be difficult to organize student records and quickly check the overall performance of a class.

The purpose of this project is to create a simple Python-based Student Grade Management System that helps manage student details, subject marks, grade calculations, report cards, and basic class performance statistics through a command-line interface.

## Scope of the Project

The project focuses on basic academic record and result management for Semester 1 students.

The system covers:

- Adding student details
- Storing student marks
- Validating marks entered by the user
- Calculating total marks and percentage
- Assigning grades
- Generating student report cards
- Viewing basic class performance statistics

The current project is designed as a command-line application. Student data is stored during program execution and is not permanently stored in a database.

## Target Users

The main target users of this project are:

- Students who want to manage and check their academic results
- Teachers who want to calculate and view basic student performance
- Users learning Python programming and basic data management

The project is mainly intended for small-scale academic record management.

## High-Level Features

The system provides the following main features:

- Add a new student using roll number and name
- Check for duplicate roll numbers
- Enter marks for Semester 1 subjects
- Validate marks between 0 to 100
- Calculate total marks
- Calulate percentage
- Assign a final grade
- Generate a student report card
- Calulate class average percentage
- Identify the top-performing student
- Handle invalid user input
- Provide a simple terminal-based menu
